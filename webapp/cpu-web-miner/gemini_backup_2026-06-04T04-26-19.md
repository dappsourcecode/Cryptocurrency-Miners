Important Technical Details
1. Why "Accepted Shares" might not show up

In the library wrapper you are using (cpuWebMiner.start), the code only exposes callbacks for Work (Job Received) and Hashrate.

Most web miner wrappers do not expose the "Share Accepted" event in their simple start function. The work object in your log is the pool giving you work, not you submitting it.

To see shares: You would usually need to inspect the WebSocket responses directly or modify the library to emit an event when the pool responds with result: true.

The workaround: In the code above, "New Job Received" confirms you are active. If your Hashrate is > 0, you are mining.

2. The "SharedArrayBuffer" Requirement

If you host this on a real website (not just opening a local file), the hashrate will be extremely low or fail unless you set specific HTTP Headers on your server.

Cross-Origin-Opener-Policy: same-origin

Cross-Origin-Embedder-Policy: require-corp

If you don't set these, the browser security will block high-performance multi-threading.

3. Antivirus

Raptoreum web miners (GhostRider) are often flagged by Windows Defender or browser safety checks as "CoinMiners." You may need to create an exception for the folder/URL where you run this.

The Missing Link: Browser Security

If you see the "New Job" logs but the Hashrate stays at 0.00 H/s (or the callback never fires), it is almost certainly because your browser is blocking the high-performance mining threads.

Modern browsers (Chrome, Edge, Firefox) disable the feature required for mining (called SharedArrayBuffer) unless the website sends two specific security "headers."

1. The Quick Test

To confirm this is the problem, press F12 to open your browser console and type this:

JavaScript
crossOriginIsolated


If it returns false: Your browser is blocking the miner. The hashrate will never show up.

If it returns true: The miner should work (check for antivirus blocking).

2. How to Fix It (The "Headers" Problem)

You cannot just double-click the .html file to open it. You must serve it via a local server that adds these headers:

Cross-Origin-Opener-Policy: same-origin

Cross-Origin-Embedder-Policy: require-corp

The Easiest Solution (Python Script)

If you have Python installed, create a file named server.py in the same folder as your HTML file and paste this code:

Python
from http.server import HTTPServer, SimpleHTTPRequestHandler

class MiningHandler(SimpleHTTPRequestHandler):
    def end_headers(self):
        self.send_header("Cross-Origin-Opener-Policy", "same-origin")
        self.send_header("Cross-Origin-Embedder-Policy", "require-corp")
        super().end_headers()

# Start the server on port 8000
print("Serving on http://localhost:8000 (Mining Headers Enabled)")
HTTPServer(('localhost', 8000), MiningHandler).serve_forever()


Run this script in your terminal: python server.py

Open your browser to: http://localhost:8000

Check crossOriginIsolated in the console again. It should now be true, and your hashrate should start appearing after 10-20 seconds.

<script type="module">
    import * as cpuWebMiner from 'https://esm.run/@marco_ciaramella/cpu-web-miner';

    // --- Config ---
    const stratum = {
        server: "europe.raptoreum.zone",
        port: 3333,
        worker: "RD45BCbByA1DxFjNnP8Zeq3ZiDbpfqKNWG.default",
        password: "x",
        ssl: false
    };

    // --- State ---
    let isMining = false;
    let sharesFound = 0;
    let targetShares = null; // null means infinite

    // --- UI Elements ---
    const btnToggle = document.getElementById('btn-toggle');
    const inputTarget = document.getElementById('input-target');
    const uiHashrate = document.getElementById('ui-hashrate');
    const uiShares = document.getElementById('ui-shares');
    const uiDiff = document.getElementById('ui-diff');
    const uiJob = document.getElementById('ui-job');
    const consoleLogs = document.getElementById('console-logs');

    // --- Logger ---
    function logToScreen(msg, color = '#a9b1d6') {
        const div = document.createElement('div');
        div.className = 'log-entry';
        div.style.color = color;
        div.innerHTML = `<span style="color: #565f89">[${new Date().toLocaleTimeString()}]</span> ${msg}`;
        consoleLogs.appendChild(div);
        consoleLogs.scrollTop = consoleLogs.scrollHeight; 
    }

    // --- Start / Stop Logic ---
    btnToggle.addEventListener('click', () => {
        if (!isMining) {
            startMining();
        } else {
            stopMining();
        }
    });

    function startMining() {
        // 1. Check Security
        if (!crossOriginIsolated) {
            logToScreen("ERROR: crossOriginIsolated is false. Check server.py or headers.", '#f7768e');
            return;
        }

        // 2. Read Target
        const targetVal = inputTarget.value;
        if (targetVal && parseInt(targetVal) > 0) {
            targetShares = parseInt(targetVal);
            logToScreen(`Starting miner. Target: ${targetShares} shares.`, '#9ece6a');
        } else {
            targetShares = null;
            logToScreen(`Starting miner. Target: Infinite.`, '#9ece6a');
        }

        // 3. Reset UI
        isMining = true;
        sharesFound = 0;
        uiShares.innerText = "0";
        uiHashrate.innerText = "Initializing...";
        
        // Update Button
        btnToggle.innerText = "Stop Mining";
        btnToggle.className = "btn-stop";
        inputTarget.disabled = true;

        // 4. Start Engine
        cpuWebMiner.start(
            cpuWebMiner.ghostrider,
            stratum,
            null,
            cpuWebMiner.ALL_THREADS,
            // WORK Callback
            (data) => {
                const job = data.work || data;
                if (job && job.jobId) {
                    uiJob.innerText = job.jobId;
                    uiDiff.innerText = job.miningDiff;
                }
            },
            // HASHRATE Callback (Treated as "Share Found")
            (data) => {
                let rateKHs = 0;
                if (data && data.hashrateKHs) rateKHs = parseFloat(data.hashrateKHs);
                else if (typeof data === 'number') rateKHs = data;

                const rateHs = (rateKHs * 1000).toFixed(2);
                
                // Update Hashrate UI
                uiHashrate.innerText = rateHs + " H/s";

                // Increment Shares
                sharesFound++;
                uiShares.innerText = sharesFound;

                logToScreen(`Share Found! (#${sharesFound}) | Speed: ${rateHs} H/s`, '#bb9af7');

                // Check Target
                if (targetShares !== null && sharesFound >= targetShares) {
                    logToScreen(`Target of ${targetShares} shares reached! Stopping...`, '#f7768e');
                    stopMining();
                }
            },
            // ERROR Callback
            (error) => {
                logToScreen(`Error: ${error.message || error}`, '#f7768e');
            }
        );
    }

    function stopMining() {
        isMining = false;
        
        // Stop Engine
        cpuWebMiner.stop();
        
        // Update UI
        btnToggle.innerText = "Start Mining";
        btnToggle.className = "btn-start";
        inputTarget.disabled = false;
        uiHashrate.innerText = "Stopped";
        
        logToScreen("Miner stopped.");
    }

</script>

How to use it:

Ensure server.py is running.

Open the page. It will not start automatically anymore.

Enter a number (e.g., 5) in the "Target Shares" box.

Click "Start Mining".

Watch the logs. It will count up: "Share Found! (#1)... (#2)...".

Once it hits #5, the miner will automatically shut down.

If you leave the box empty, it runs forever until you click "Stop".
